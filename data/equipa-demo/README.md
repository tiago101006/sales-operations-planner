# Equipa de demonstração NexoPlan

Dez identidades e retratos inteiramente fictícios, para simular uma equipa de
planeamento de uma distribuidora. Os nomes não identificam funcionários reais.
Os retratos foram criados com a ferramenta Imagegen integrada e normalizados
para JPEG de 256 × 256 píxeis, conforme o formato de fotografia da aplicação.

O [manifesto](manifesto.json) conserva nomes, emails `@nexoplan.com`, perfis,
estado, correspondência com os identificadores históricos, prompts e SHA-256 das
fotografias. Não contém palavras-passe.
